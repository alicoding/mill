# Mind map

Shows a note's headings as a mind map that follows the note as it
changes. The map is a drawing fitted to its box, redrawn whenever the
source note's content changes.

## Settings

None.

## Capabilities

None -- the map only reads a note already on the board.

## Try it

Copy the `mill-markmap` folder into Mill's plugins folder (Settings >
Extensions > Open plugins folder) and reload plugins. Add a note with
a few headings, place a Mind map object, and pick that note.
