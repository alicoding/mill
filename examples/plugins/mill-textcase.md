# Text case

A workflow step that changes text's case: upper, lower, or title.
Nothing renders on the board -- the step runs inside Mill's workflow
executor, and is also reachable by an agent over MCP.

## Settings

None.

## Capabilities

None.

## Try it

Copy the `mill-textcase` folder into Mill's plugins folder (Settings >
Extensions > Open plugins folder) and reload plugins. Add its "Text
case" step to a workflow and pick a mode.
