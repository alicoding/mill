# Bruno collection

Keeps a Bruno API collection on the board by mirroring its
`bruno.json`, and shows what it is: its name, its request count, and a
button that opens it in Bruno. The seeded example workflow runs the
collection and lands the results in a List.

## Settings

None.

## Capabilities

- `open-app` -- opens the collection's folder in Bruno, on your
  approval.
- `list-files` -- lists the collection's `.bru` requests.

## Try it

Copy the `mill-bruno` folder into Mill's plugins folder (Settings >
Extensions > Open plugins folder) and reload plugins. Place a Bruno
collection object and enter the path to a collection's `bruno.json`.
