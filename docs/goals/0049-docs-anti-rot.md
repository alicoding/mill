# 0049 — Docs anti-rot mechanics

**Raised:** 2026-08-13, owner-directed after a two-agent survey
(repo doc inventory + industry research: Google's SWE-book
documentation chapter, GitLab's docs-testing pipeline, the ICSE 2019
doc-rot taxonomy, Anthropic/Cursor/AGENTS.md context-file guidance).
Full findings live in this file's Research section below; the verdict
was that Mill already runs the highest-leverage practices (progressive
disclosure, colocation, immutable ADRs, seeds-as-executable-proof,
dependency-cruiser) and the remaining gaps are all mechanical.

## Design principle (from the research, load-bearing)

Every anti-staleness mechanism with real teeth works because the doc's
content is checkable against something already forced to be true.
Prose that is original judgment has no CI-checkable freshness
mechanism anywhere in the industry — Google's freshness-date +
owner-nagging system requires a non-author enforcer and degenerates
solo into a false freshness signal. So: adopt only machine-enforced
checks; reject social-enforcement imports.

## Scope (all mechanical, all solo-compatible)

1. **Docs path-reference checker** — the dominant Mill-specific rot
   mode: docs/ (SPEC, ADRs, goals) cite concrete repo paths
   constantly. A script verifying that repo paths referenced in
   `docs/**/*.md` exist, wired lefthook + CI (the exact
   one-script-two-callers shape of `check-loc.sh`/`check-ui-copy.sh`).
   Needs a deliberate extraction heuristic (backticked path-shaped
   tokens; an allowlist/skip marker for deliberately-historical paths
   in ADRs — an ADR describing a since-moved file is history, not rot;
   scope the hard-fail to non-archive, non-ADR docs if precision
   demands, but SPEC.md and active goals always check).
2. **Generated ADR index** — `docs/adr/README.md` generated from the
   files' ids + titles (never hand-written, so it cannot drift);
   regenerated by the same script/CI job, failing when committed index
   ≠ regenerated.
3. **Go package-comment floor** — enable revive's `package-comments`
   rule in `.golangci.yml`; fill the ~10 packages currently missing a
   package comment (one Sonnet sweep); the linter holds the floor
   forever after.
4. **AGENTS.md interop** — expose the same always-loaded context to
   non-Claude agents (repo is heading to open source): the
   documented pattern is a root AGENTS.md that shares content with
   CLAUDE.md via symlink or import rather than duplication. Decide
   direction (which file is the source) in-goal; zero ongoing
   maintenance either way.
5. **README stale-line fix** — README still claims SPEC.md renders
   inside the app (Spec view retired 2026-08-10). One line; the
   path-reference checker class won't catch claims-about-features, so
   it rides here as the found instance.

## Rejected, with reasons (recorded so they aren't re-litigated)

- Google-style freshness dates/owner nagging — needs a non-author
  enforcer; solo it produces false freshness signals.
- Human "docs-or-it-didn't-happen" PR gate — gatekeeper == author is
  the failure the pattern exists to prevent; the CI-executable
  variant IS adopted (items 1–2).
- `llms.txt` — one more hand-maintained index with no internal
  read-path; the exact goes-stale anti-pattern this goal targets.
- Swimm-class drift-detection SaaS — hosted-service dependency,
  disqualified by SPEC §1.1 before evaluating vendor claims.
- repomix-pack-in-CI — pack-on-demand already works (MCP); a
  committed pack is instantly stale.
- SPEC.md restructuring — the same-change-update rule already in
  force is the industry state of the art for judgment prose; no
  mechanism exists to adopt.

      pre-commit AND a CI job; a doc referencing a nonexistent repo

      is documented in the script header.
- [ ] `docs/adr/README.md` exists, is generated, and CI fails if it
      drifts from the ADR file set.

      real package comments (constraints/purpose, not restated names).
- [ ] AGENTS.md resolves to the same content as CLAUDE.md (mechanism
      decided and recorded in this file when implemented).

- [ ] SPEC.md §9.1 (context engineering) gains a one-bullet status
